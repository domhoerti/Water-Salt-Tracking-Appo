Sicherung über GitHub

Ein privates Repo verbinden: Die App legt dort nach jeder Änderung daten.json ab. Damit sind deine Daten gesichert und auf allen Geräten gleich. Der Zugriffsschlüssel bleibt auf diesem Gerät und landet nie im Repo.

Schlüssel erzeugen: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Nur dieses eine Repo auswählen, Berechtigung Contents: Read and write, sonst nichts.
